# Les histoires de Pistache

Histoires illustrées et lues à voix haute pour les tout-petits, avec Pistache le petit dragon et Biscotte la chienne sauveteuse.

Application web installable (PWA) : ouvrir le lien dans Chrome sur Android, puis menu ⋮ → « Installer l'application ». Fonctionne hors connexion après la première ouverture.
